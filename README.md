# המאוחדת — אתר הקבוצה

אתר סטטי בקובץ אחד (`index.html`). אין התקנה, אין שרת ואין כלי בנייה —
פותחים את הקובץ בדפדפן וזה עובד.

## איך מעדכנים תוכן

כל התוכן נמצא בבלוק אחד בתחתית `index.html`, מתחת לשורה:

```
★★★  כל התוכן של האתר נמצא כאן  ★★★
```

| משתנה        | מה זה                                                     |
| ------------ | --------------------------------------------------------- |
| `TEAM`       | שם הקבוצה, משפט הפתיחה, קישורים, קובץ הלוגו וצבעי הקבוצה  |
| `STATS`      | המספרים הגדולים בראש העמוד (ריק = חישוב אוטומטי לפי הסגל) |
| `NEWS`       | עדכוני החדשות                                             |
| `SQUAD`      | רשימת השחקנים                                             |
| `STAFF`      | ההנהלה — בעלים, מנכ״ל, מנהל קבוצה (ריק = האזור לא מוצג)   |
| `LEAGUE`     | טבלת הליגה (ריק = אזור הטבלה לא מוצג באתר)                |
| `PODCASTS`   | פרקי "הבה נרגילה"                                         |
| `GALLERY`    | תמונות הגלריה                                             |
| `IG_POSTS`   | קישורים לפוסטים מאינסטגרם להטמעה                          |
| `NEXT_MATCH` | פרטי המשחק הבא שמופיעים בכרטיס המידע בראש האתר            |

## שחקן

```js
{ name:'אייל חזן', pos:'חלוץ / קשר', cat:'התקפה', photo:'', n:11 }
```

- `pos` — העמדה כפי שהיא מוצגת על הכרטיס. טקסט חופשי.
- `cat` — הקטגוריה לסינון: `שוער` / `הגנה` / `קישור` / `התקפה`.
  מוצגים רק כפתורי סינון של עמדות שקיימות בפועל בסגל.
- `n` — מספר חולצה. אם לא ממלאים, פשוט לא יוצג מספר.
- `photo` — למשל `'images/eyal.jpg'`. ריק = עיגול עם ראשי התיבות.
- `captain:true` — תג "קפטן".
- `status:'פצוע'` — תג אדום, הכרטיס מקבל גוון אפור ונוסף כפתור סינון "פצועים".
- `apps` / `goals` / `assists` — סטטיסטיקה. אם לא ממלאים, שורת המספרים
  לא מוצגת בכלל — כך אף אחד לא נראה כאילו כבש 0 שערים.
  ברגע שממלאים, טבלאות מלך השערים ומלך הבישולים מתמלאות לבד.

## סטטיסטיקה של כל הזמנים

כל שער שנרשם מהקו נכנס מיד לסיכומי הקריירה, לטבלאות ולכרטיסי השחקנים.
אין מונים ששומרים בצד. הכל מחושב מחדש מהאירועים עצמם בכל טעינה.

| כתובת             | מה יש שם                                                                    |
| ----------------- | --------------------------------------------------------------------------- |
| `/stats`          | טבלת כל הזמנים: תרומה כוללת, מלך השערים, מלך הבישולים. סינון לפי עונה/סגל פעיל |
| `/players/<שם>`   | כרטיס קריירה: מספרים, תגים, פירוט לפי עונה ויומן משחקים עם חיפוש              |
| `/live`           | מצב קו לטלפון: פתיחת משחק, הרכב, רישום שערים                                 |
| `/admin`          | הזנת נתונים היסטוריים, פעיל/בוגר, תיקון משחקים                               |

### רישום מהקו (`/live`)

1. ממלאים יריבה ותאריך, ומסמנים מי משחק היום. שחקנים שלא סומנו, ובוגרים, לא
   יופיעו בבחירה.
2. **⚽ שער!** ← מי כבש ← בישול ראשון (או "סולו") ← בישול שני (או "ללא") ← **אישור**.
3. אחרי כל פעולה מופיע כפתור **ביטול הפעולה האחרונה** למשך 60 שניות.
4. **🏁 סיום** (שתי לחיצות) סוגר את המשחק.

כל שער נשמר קודם בטלפון ורק אז נשלח לענן. בלי קליטה מופיע "ממתינים לקליטה",
והשליחה חוזרת לבד כשהחיבור חוזר. טעות שהתגלתה אחרי 60 השניות מתקנים
ב-`/admin` ← משחקים. מוחקים את השער ורושמים אותו מחדש.

- גם הקו וגם הניהול נעולים ב-`editCode`, בדיוק כמו פאנל ההוספה.
- `apps` / `goals` / `assists` שממולאים ב-`SQUAD` נספרים כרישום היסטורי
  בתקופה "לפני המעקב".
- כתובות כמו `/stats` עובדות בזכות `404.html`, שמחזיר לדף הראשי. בפתיחה
  מקומית של הקובץ משתמשים ב-`#/stats`.
- האירועים נשמרים ב-Cloudinary בתווית `stats`, ולכן גם כאן **Resource list**
  חייב להיות פתוח.

## הנהלה

```js
const STAFF = [
  { role: "בעלים", name: "ישראל ישראלי", note: "מאז 2019", photo: "" },
];
```

- `role` — התפקיד, מוצג בגדול על הכרטיס.
- `name` — אם ריק, מוצג "טרם עודכן" עד שממלאים.
- `note` — שורת תיאור קצרה, אופציונלי.
- תמונה אפשר להעלות מתוך האתר, בדיוק כמו לשחקנים.
- רשימה ריקה = אזור ההנהלה והקישור אליו בתפריט לא מופיעים.

## הלוגו

כרגע מוצג סמל SVG שבניתי בהשראת הסמל האמיתי. כדי להשתמש במקורי:

1. שומרים את קובץ הסמל בתור `images/logo.png` (רצוי PNG עם רקע שקוף).
2. ב־`TEAM` משנים ל־`logo: 'images/logo.png'`.

הסמל יוחלף אוטומטית בכל מקום שבו הוא מופיע — בתפריט, בכותרת ובפוטר.

```js
colors: { main:'#e6b647', second:'#cf2033' }   // זהב ואדום, לפי הסמל
```

## אזור הטבלה

`LEAGUE` ריק כרגע, ולכן כל אזור הטבלה — כולל הקישור אליו בתפריט —
פשוט לא מופיע באתר. ברגע שממלאים שורות הוא חוזר לבד:

```js
const LEAGUE = [
  {
    team: "המאוחדת",
    p: 24,
    w: 16,
    d: 4,
    l: 4,
    gf: 96,
    ga: 54,
    form: ["W", "W", "D", "W", "L"],
    us: true,
  },
];
```

- `us:true` מדגיש את השורה שלנו.
- `form` — חמשת המשחקים האחרונים: `W` ניצחון, `D` תיקו, `L` הפסד.
- הנקודות, הפרש השערים והדירוג מחושבים לבד.

באותו אזור יושבים גם מלך שערים ומלך בישולים. הם מופיעים בנפרד, ברגע
שממלאים `goals` או `assists` לשחקנים — גם בלי טבלת ליגה.

## מצבי "בקרוב"

`PODCASTS` ו־`GALLERY` ריקים כרגע, ולכן האתר מציג בשני הסקשנים כרטיס
"בקרוב" עם קישור לאינסטגרם — במקום אזור ריק שנראה שבור.
ברגע שמוסיפים שורה לרשימה, הכרטיס נעלם והתוכן האמיתי מופיע.

### להוסיף פרק פודקאסט

```js
const PODCASTS = [
  {
    n: 10,
    title: "דביר דמתי מתארח",
    date: "ראשון",
    duration: "45 דק׳",
    desc: "תיאור קצר של הפרק.",
    embed: "https://open.spotify.com/embed/episode/XXXX",
  },
];
```

בספוטיפיי: שיתוף ← Embed ← מעתיקים את כתובת ה־`src` מתוך ה־`iframe`.
ביוטיוב: `https://www.youtube.com/embed/VIDEO_ID`.
פרק בלי `embed` יוצג עם הכותרת והתיאור, בלי נגן.
פרק חדש = שורה חדשה בראש הרשימה.

### להוסיף עדכון חדשות

מוסיפים שורה בראש `NEWS` — העדכון החדש נכנס למעלה:

```js
const NEWS = [
  {
    date: "12 בספטמבר",
    tag: "משחק",
    title: "ניצחון בדרבי",
    text: "גוף העדכון.",
    image: "images/news-derby.jpg", // אופציונלי
    link: "https://www.instagram.com/p/XXXX/",
  }, // אופציונלי
];
```

- `tag` — תווית קטנה: הכרזה / משחק / פודקאסט / ציוד, מה שרוצים.
- בלי `image` הכרטיס נפרס על כל הרוחב.
- עדכון שהתמונה שלו עוד לא הועלתה יוצג בלי תמונה, לא עם ריבוע שבור.
- `link` מוסיף קישור "קראו עוד" בתחתית הכרטיס.

### להוסיף תמונות, חדשות ופרקים — מתוך האתר

באתר יש כפתור **"הוספת תוכן"** בפינה. הוא פותח פאנל עם לשוניות להוספה
ועריכה:

| לשונית        | מה עושים                                                                   |
| ------------- | -------------------------------------------------------------------------- |
| תמונות לגלריה | גוררים או בוחרים תמונות, כמה בבת אחת, עם כותרת אופציונלית                  |
| תמונת אדם     | בוחרים שחקן או איש הנהלה ומעלים תמונה. אפשר גם דרך כפתור המצלמה שעל הכרטיס |
| עדכון חדשות   | כותרת, טקסט, תווית ותמונה                                                  |
| פרק פודקאסט   | מספר, כותרת, תיאור וקישור הטמעה                                            |
| סרטון למדיה   | סרטון, כותרת ומשתתפים                                                      |
| עריכת סרטון   | שינוי כותרת, משתתפים ותגית בלי להעלות או למחוק את הסרטון                   |

הכל נשמר ב-Cloudinary ומופיע מיד אצל מי שהעלה. אצל שאר הגולשים זה
מופיע תוך כדקה, כי רשימת התוכן נשמרת זמנית ב-CDN.

### מדיה

בטאב **מדיה** מוצגים הסרטונים בגריד בסגנון רשת חברתית. לחיצה על סרטון
פותחת נגן עם הכותרת והמשתתפים, ויש בו גם כפתור **פתיחה במסך מלא**.

כדי להוסיף סרטון: לוחצים על **הוספת תוכן** ← **סרטון למדיה**, ממלאים
כותרת ומשתתפים, בוחרים קובץ וידאו ולוחצים על **העלאת הסרטון**.
הסרטון נשמר ב-Cloudinary כמשאב מסוג `video`, והפרטים נשמרים כמסמך
במדיה כדי שיופיעו גם לאחר רענון האתר.

לכל סרטון אפשר לבחור סוג תוכן — משחק, ראיון, מאחורי הקלעים, רגע מהקבוצה או
שיר שחקן.
הסוג מופיע על הכרטיס ויוצר מסננים בראש הגלריה. הסרטון הראשון שמופיע מקבל
תצוגה רחבה יותר כדי להדגיש את התוכן החדש. כדי לערוך סרטון קיים, לוחצים על
**✎ עריכה** בכרטיס, משנים את הפרטים ולוחצים על **שמירת השינויים**. נשמר מסמך
מטא-דאטה חדש, בעוד שקובץ הווידאו המקורי נשאר ללא שינוי.

### המשחק הבא

כרטיס "המשחק הבא" נמצא בראש האתר. כדי לעדכן אותו ממלאים את האובייקט הבא:

```js
const NEXT_MATCH = {
  opponent: "FC MEHUEDET",
  venue: "תיכון אורט",
};
```

האתר מחשב לבד את המשחק הבא ליום שישי בשעה 15:00 ומציג ספירה לאחור
שמתאפסת אוטומטית בכל שבוע. כדי לשנות את היריבה או את המיקום, מעדכנים את
האובייקט בלבד.

האתר כולל גם תפריט נפתח למובייל, סימון אוטומטי של האזור הפעיל, הודעות הצלחה
לאחר העלאה, focus נגיש למקלדת ותמיכה בהפחתת אנימציות למשתמשים שהפעילו זאת
במערכת ההפעלה.

ה-preset של Cloudinary צריך לאפשר העלאות וידאו בנוסף לתמונות. אם הסרטון
הועלה אך לא מופיע לאחר רענון, יש לוודא שגם **Resource list** פתוח ב-
**Settings → Security**.

התמונות נדחסות בדפדפן לפני ההעלאה, כך שתמונה של 5 מגה מהטלפון לא
מאיטה את האתר.

### הגדרות Cloudinary

ב-`TEAM.cloudinary` יושבים שני ערכים מהדשבורד:

```js
cloudinary: { cloudName:'mrobhtey', uploadPreset:'w1u89zju' },
```

- ה-preset חייב להיות במצב **Unsigned**.
- ב-**Settings → Security** האפשרות **Resource list** חייבת להיות פתוחה,
  אחרת האתר לא יוכל לקרוא את רשימת התוכן והכל ייראה ריק אחרי רענון.
- אם מוחקים את שני הערכים, כפתור ההוספה נעלם והאתר חוזר לעבוד בלעדיו.

### מי רשאי להוסיף

```js
editCode: '',
```

ריק = כל מי שנכנס לאתר יכול להוסיף תוכן, בלי סיסמה.
מילוי קוד כאן נועל את הפאנל מיד לכל מי שלא יודע אותו. הקוד נשמר
בדפדפן של מי שהקליד אותו, כך שהוא לא צריך להזין אותו בכל פעם.

### מחיקה

מחיקת תמונה או עדכון נעשית מהדשבורד של Cloudinary, לא מהאתר.
זה מכוון: העלאה אנונימית מותרת, אבל מחיקה אנונימית הייתה מאפשרת
לכל אחד למחוק את כל הגלריה.

### תמונות שיושבות בריפו

אפשר גם להעלות קבצים לתיקייה `images` בשמות `1.jpg`, `2.jpg` וכן הלאה,
והם ייכנסו לגלריה אחרי הדיפלוי הבא. `GALLERY_SLOTS` קובע עד איזה מספר
לבדוק, ו-`GALLERY_CAPTIONS` מאפשר לתת להם כותרות.

## התראות לטלפון

כל עדכון חדשות, פרק פודקאסט, סרטון או תמונות לגלריה שמתפרסמים מתוך האתר
שולחים התראה לטלפונים של מי שנרשם. אין שרת ואין עלות. ההתראות עוברות דרך
[ntfy.sh](https://ntfy.sh), שירות חינמי שלא דורש הרשמה.

```js
notify: { server: "https://ntfy.sh", topic: "hameuhedet-fc-ee752be3" },
```

- **לאוהדים:** כפתור **🔔 התראות** בתפריט (וגם ליד כפתור האינסטגרם) פותח
  הסבר קצר: מתקינים את האפליקציה ntfy (אנדרואיד / אייפון) ולוחצים
  "הרשמה בלחיצה". במחשב אפשר להירשם מהדפדפן, בלי אפליקציה.
- **למפרסמים:** בפאנל ההוספה יש תיבה "לשלוח התראה לטלפונים של האוהדים".
  היא מסומנת כברירת מחדל. מורידים את הסימון כדי לפרסם בשקט (למשל תיקון קטן).
- תוכן נעול לא נחשף בהתראה. נשלח רק "תוכן נעול חדש 🔒".
- לחיצה על ההתראה פותחת את האתר ישר בסקשן הרלוונטי. בחדשות עם תמונה,
  בסרטונים ובגלריה התמונה מופיעה בתוך ההתראה.
- התראה שנכשלה (למשל בלי קליטה) לא עוצרת את הפרסום עצמו.
- `topic` הוא שם הערוץ. **כל מי שיודע אותו יכול גם לשלוח אליו**, ולכן
  הוא מכיל רצף אקראי. אם מישהו מתחיל לשלוח ספאם, מחליפים את השם, והאוהדים
  נרשמים מחדש. `topic` ריק = הכפתור נעלם ולא נשלחות התראות.
- שינוי מהדשבורד של Cloudinary, או עריכת סרטון קיים, לא שולחים התראה.
