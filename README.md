# המאוחדת — אתר הקבוצה

אתר סטטי בקובץ אחד (`index.html`). אין התקנה, אין שרת ואין כלי בנייה —
פותחים את הקובץ בדפדפן וזה עובד.

## איך מעדכנים תוכן

כל התוכן נמצא בבלוק אחד בתחתית `index.html`, מתחת לשורה:

```
★★★  כל התוכן של האתר נמצא כאן  ★★★
```

| משתנה       | מה זה                                                        |
|-------------|---------------------------------------------------------------|
| `TEAM`      | שם הקבוצה, משפט הפתיחה, קישורים, קובץ הלוגו וצבעי הקבוצה     |
| `STATS`     | המספרים הגדולים בראש העמוד (ריק = חישוב אוטומטי לפי הסגל)     |
| `NEWS`      | עדכוני החדשות                                                  |
| `SQUAD`     | רשימת השחקנים                                                 |
| `LEAGUE`    | טבלת הליגה (ריק = אזור הטבלה לא מוצג באתר)                    |
| `PODCASTS`  | פרקי "הבה נרגילה"                                             |
| `GALLERY`   | תמונות הגלריה                                                  |
| `IG_POSTS`  | קישורים לפוסטים מאינסטגרם להטמעה                              |

## שחקן

```js
{ name:'אייל חזן', pos:'חלוץ / קשר', cat:'התקפה', photo:'', n:11 }
```

- `pos` — העמדה כפי שהיא מוצגת על הכרטיס. טקסט חופשי.
- `cat` — הקטגוריה לסינון: `שוער` / `הגנה` / `קישור` / `התקפה`.
  מוצגים רק כפתורי סינון של עמדות שקיימות בפועל בסגל.
- `n` — מספר חולצה. אם לא ממלאים, פשוט לא יוצג מספר.
- `photo` — למשל `'images/eyal.jpg'`. ריק = עיגול עם ראשי התיבות.
- `captain:true` — תג "קפטן".
- `status:'פצוע'` — תג אדום, הכרטיס מקבל גוון אפור ונוסף כפתור סינון "פצועים".
- `apps` / `goals` / `assists` — סטטיסטיקה. אם לא ממלאים, שורת המספרים
  לא מוצגת בכלל — כך אף אחד לא נראה כאילו כבש 0 שערים.
  ברגע שממלאים, טבלאות מלך השערים ומלך הבישולים מתמלאות לבד.

## הלוגו

כרגע מוצג סמל SVG שבניתי בהשראת הסמל האמיתי. כדי להשתמש במקורי:

1. שומרים את קובץ הסמל בתור `images/logo.png` (רצוי PNG עם רקע שקוף).
2. ב־`TEAM` משנים ל־`logo: 'images/logo.png'`.

הסמל יוחלף אוטומטית בכל מקום שבו הוא מופיע — בתפריט, בכותרת ובפוטר.

## צבעי הקבוצה

שתי שורות משנות את כל האתר:

```js
colors: { main:'#e6b647', second:'#cf2033' }   // זהב ואדום, לפי הסמל
```

## אזור הטבלה

`LEAGUE` ריק כרגע, ולכן כל אזור הטבלה — כולל הקישור אליו בתפריט —
פשוט לא מופיע באתר. ברגע שממלאים שורות הוא חוזר לבד:

```js
const LEAGUE = [
  { team:'המאוחדת', p:24, w:16, d:4, l:4, gf:96, ga:54,
    form:['W','W','D','W','L'], us:true }
];
```

- `us:true` מדגיש את השורה שלנו.
- `form` — חמשת המשחקים האחרונים: `W` ניצחון, `D` תיקו, `L` הפסד.
- הנקודות, הפרש השערים והדירוג מחושבים לבד.

באותו אזור יושבים גם מלך שערים ומלך בישולים. הם מופיעים בנפרד, ברגע
שממלאים `goals` או `assists` לשחקנים — גם בלי טבלת ליגה.

## מצבי "בקרוב"

`PODCASTS` ו־`GALLERY` ריקים כרגע, ולכן האתר מציג בשני הסקשנים כרטיס
"בקרוב" עם קישור לאינסטגרם — במקום אזור ריק שנראה שבור.
ברגע שמוסיפים שורה לרשימה, הכרטיס נעלם והתוכן האמיתי מופיע.

### להוסיף פרק פודקאסט

```js
const PODCASTS = [
  { n:10, title:'דביר דמתי מתארח', date:'ראשון', duration:'45 דק׳',
    desc:'תיאור קצר של הפרק.',
    embed:'https://open.spotify.com/embed/episode/XXXX' }
];
```

בספוטיפיי: שיתוף ← Embed ← מעתיקים את כתובת ה־`src` מתוך ה־`iframe`.
ביוטיוב: `https://www.youtube.com/embed/VIDEO_ID`.
פרק בלי `embed` יוצג עם הכותרת והתיאור, בלי נגן.
פרק חדש = שורה חדשה בראש הרשימה.

### להוסיף עדכון חדשות

מוסיפים שורה בראש `NEWS` — העדכון החדש נכנס למעלה:

```js
const NEWS = [
  { date:'12 בספטמבר', tag:'משחק',
    title:'ניצחון בדרבי',
    text:'גוף העדכון.',
    image:'images/news-derby.jpg',                 // אופציונלי
    link:'https://www.instagram.com/p/XXXX/' }     // אופציונלי
];
```

- `tag` — תווית קטנה: הכרזה / משחק / פודקאסט / ציוד, מה שרוצים.
- בלי `image` הכרטיס נפרס על כל הרוחב.
- עדכון שהתמונה שלו עוד לא הועלתה יוצג בלי תמונה, לא עם ריבוע שבור.
- `link` מוסיף קישור "קראו עוד" בתחתית הכרטיס.

### להוסיף תמונות, חדשות ופרקים — מתוך האתר

באתר יש כפתור **"הוספת תוכן"** בפינה. הוא פותח פאנל עם ארבע לשוניות:

| לשונית | מה עושים |
|--------|-----------|
| תמונות לגלריה | גוררים או בוחרים תמונות, כמה בבת אחת, עם כותרת אופציונלית |
| תמונת שחקן | בוחרים שחקן ומעלים לו תמונה. אפשר גם דרך כפתור המצלמה שעל הכרטיס |
| עדכון חדשות | כותרת, טקסט, תווית ותמונה |
| פרק פודקאסט | מספר, כותרת, תיאור וקישור הטמעה |

הכל נשמר ב-Cloudinary ומופיע מיד אצל מי שהעלה. אצל שאר הגולשים זה
מופיע תוך כדקה, כי רשימת התוכן נשמרת זמנית ב-CDN.

התמונות נדחסות בדפדפן לפני ההעלאה, כך שתמונה של 5 מגה מהטלפון לא
מאיטה את האתר.

### הגדרות Cloudinary

ב-`TEAM.cloudinary` יושבים שני ערכים מהדשבורד:

```js
cloudinary: { cloudName:'mrobhtey', uploadPreset:'w1u89zju' },
```

- ה-preset חייב להיות במצב **Unsigned**.
- ב-**Settings → Security** האפשרות **Resource list** חייבת להיות פתוחה,
  אחרת האתר לא יוכל לקרוא את רשימת התוכן והכל ייראה ריק אחרי רענון.
- אם מוחקים את שני הערכים, כפתור ההוספה נעלם והאתר חוזר לעבוד בלעדיו.

### מי רשאי להוסיף

```js
editCode: '',
```

ריק = כל מי שנכנס לאתר יכול להוסיף תוכן, בלי סיסמה.
מילוי קוד כאן נועל את הפאנל מיד לכל מי שלא יודע אותו. הקוד נשמר
בדפדפן של מי שהקליד אותו, כך שהוא לא צריך להזין אותו בכל פעם.

### מחיקה

מחיקת תמונה או עדכון נעשית מהדשבורד של Cloudinary, לא מהאתר.
זה מכוון: העלאה אנונימית מותרת, אבל מחיקה אנונימית הייתה מאפשרת
לכל אחד למחוק את כל הגלריה.

### תמונות שיושבות בריפו

אפשר גם להעלות קבצים לתיקייה `images` בשמות `1.jpg`, `2.jpg` וכן הלאה,
והם ייכנסו לגלריה אחרי הדיפלוי הבא. `GALLERY_SLOTS` קובע עד איזה מספר
לבדוק, ו-`GALLERY_CAPTIONS` מאפשר לתת להם כותרות.

## תצוגה מקומית

פותחים את `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000/football/
```
