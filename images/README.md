# תמונות האתר

## גלריה

מעלים לכאן קבצים בשמות **`1.jpg`, `2.jpg`, `3.jpg`** וכן הלאה,
והם מופיעים בגלריה באתר לבד — אין צורך לגעת בקוד.

- נתמכים `jpg`, `jpeg`, `png` ו-`webp`.
- מותר לדלג על מספרים. אם קיימים 1, 2 ו-5 — יוצגו שלוש תמונות.
- ברירת המחדל היא בדיקה עד מספר 24. להעלאת יותר, מגדילים את
  `GALLERY_SLOTS` ב-`index.html`.
- כותרות לתמונות (אופציונלי) נכנסות ב-`GALLERY_CAPTIONS` לפי המספר.

עדיף להעלות את התמונה המקורית מאינסטגרם ולא צילום מסך —
בצילום מסך נכנסות גם שורת הסוללה והתגובות.

## לוגו

`logo.png` — הסמל המקורי של הקבוצה, רצוי עם רקע שקוף.
אחרי ההעלאה משנים ב-`index.html` ל-`logo: 'images/logo.png'`
והוא יחליף את סמל ה-SVG בכל האתר.

## תמונות שחקנים

כל שם קובץ שרוצים, למשל `hazan.jpg`, ואז ב-`SQUAD`:
`photo:'images/hazan.jpg'`.
